Hero media 3D

.hero__media[data-hero-media]: full-bleed 16:7 strip (max-height 72vh, --surface-raised, no radius) holding a decorative WebGL canvas.hero__canvas[aria-hidden] (src/pages/hero-3d.js, lazy after first paint). A chain of ball-sprite pills along a Catmull-Rom curve with helical spin, formation on load, pointer scatter and camera parallax.

  • Ball colours are tokens: highlight --c-blue-400, mid --c-blue-600, base --accent, edge --c-blue-950.
  • Constants: PER_RUNG 260, BALL_RADIUS 0.058, INFLUENCE_RADIUS 1.3, MAX_SCATTER 1.6, FORM_TOTAL 1.4; camera FIT_MARGIN 1.22.
  • Size from the container, DPR up to 1.5, up to 45 fps, paused off-screen or when the tab is hidden.
  • prefers-reduced-motion: a single static frame of the formed chain, no loop, hover or parallax.
  • Fallback: img.hero__image (truck.jpg) is hidden while 3D works; shown without JS or when WebGL fails (.hero--no3d). Decorative only.

Motion

Restrained, business-like motion. Only opacity and transform move; 150-600 ms; ease-out; no bounce or spring. Under prefers-reduced-motion: reduce everything is off (no reveal, no transitions, no smooth scroll, no page transition).

  • Tokens: --dur-fast 150ms, --dur-base 250ms, --dur-slow 600ms, --ease-out, --ease-in-out, --reveal-distance 16px, --stagger 60ms.
  • Smooth scroll: Lenis (duration 1.1, expo-out), initialised in src/motion.js (window.lenis). Anchors scroll with an offset equal to --header-h.
  • Reveal: data-reveal="up|fade|scale-in", data-reveal-delay="N" (0-20 = stagger index, larger = ms), data-reveal-stagger on a container (children in turn, max 8 delayed). Once only. Hidden only when JS added html.js. Hero: data-reveal-load="0,1,2" plays on load. For dynamic elements call window.__revealRefresh().
  • Hover/focus: colour/background/border transitions 150-250 ms; product-card lifts 3px; arrow icons nudge 2px diagonally; no pulse, no photo zoom.
  • Isoline shader background (Product): src/pages/product-bg.js, token --shader-line (lines) on --surface (fill), CONFIG constants at the top of the module (lineStrength 0.7, lineFreq 6.0, driftSpeed 0.12, patternScale 0.0022, lineWidth 1.3, fillBands 1, fillStrength 0.05, visVariation 0.55, visScale 0.0009). Rules: decorative only (aria-hidden); a single static frame under prefers-reduced-motion; paused when the tab is hidden; about 30 fps, DPR capped at 1.5; without WebGL or on compile failure the canvas is removed and the solid --surface remains.
  • Page transition: cross-document View Transition (200-250 ms fade); the header panel keeps its own name (site-header) so it does not flicker.
